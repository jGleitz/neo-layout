# Neo-Tastaturlayout: Bessere Implementierung für Mac OS X

Dies ist ein Fork des [git-Repositories des Neo-Tastaturlayouts](https://git.neo-layout.org/neo/neo-layout).
Er widmet sich einer verbesserten Umsetzung auf Mac OS X, mit zwei primären Zielen:

  1. Bessere Verwendbarkeit ohne Karabiner-Elements
  2. Volle Funktionalität mit Karabiner-Elements

Bei erfolgreicher Umsetzung sollen die Verbesserungen ins Haupt-Repository zurückfließen.
